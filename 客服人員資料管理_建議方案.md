# 客服人員資料管理 - 建議方案

**日期：** 2025年11月24日  
**目標：** 定義 `operator_id`, `operator_name`, `operator_avatar` 三個欄位的資料來源

---

## 📊 三個欄位的定義

| 欄位 | 用途 | 資料來源 |
|-----|------|---------|
| `operator_id` | 客服人員唯一識別碼 | 登入系統或 localStorage |
| `operator_name` | 客服人員顯示名稱 | 個人設定 |
| `operator_avatar` | 客服人員頭像 URL | 個人上傳或使用預設 |

---

## 🎯 方案一：簡易版（localStorage + 統一頭像）

### 適用場景
- 小型團隊（1-3 位客服）
- 快速上線
- 不需要複雜權限管理

### 實作方式

```javascript
// 載入個人設定
function loadOperatorProfile() {
  const stored = localStorage.getItem('operator_profile');
  if (stored) {
    const profile = JSON.parse(stored);
    document.getElementById('operator-id').value = profile.id;
    document.getElementById('operator-name').value = profile.name;

  // 載入統一頭像

// 儲存個人設定
function saveOperatorProfile() {
  const profile = {
    id: document.getElementById('operator-id').value,
    name: document.getElementById('operator-name').value || '客服人員',
    avatar: ''  // 不儲存，接手時從 branding 取得
  };
  
  localStorage.setItem('operator_profile', JSON.stringify(profile));
  alert('✅ 個人資料已儲存');
}

// 接手對話時取得完整資料
async function getOperatorInfoForTakeover() {
  const profile = JSON.parse(localStorage.getItem('operator_profile') || '{}');
  
  // 取得統一頭像
  const brandingResponse = await fetch('/api/branding');
  const branding = await brandingResponse.json();
  
  return {
    operator_id: profile.id || 'admin',
    operator_name: profile.name || '客服人員',
    operator_avatar: branding.repair_operator_avatar || '/static/avatars/default_operator.png'
  };
}
```

### 優點
✅ 實作簡單，快速上線  
✅ 不需要資料庫調整  
✅ 與 Phase 1 完美整合  

### 缺點
❌ 無法為每位客服設定獨立頭像  
❌ localStorage 資料可能遺失  
❌ 無法跨裝置同步

## 🎯 方案二：進階版（資料庫 + 個人頭像）

### 適用場景
- 中大型團隊（3+ 位客服）
- 需要跨裝置登入
- 需要獨立的頭像和權限管理

### 資料庫設計

#### 1. 建立客服人員資料表

```sql
-- 客服人員資料表
CREATE TABLE operators (
  operator_id TEXT PRIMARY KEY,           -- 員工編號
  display_name TEXT NOT NULL,             -- 顯示名稱
  avatar_url TEXT,                        -- 個人頭像 URL
  email TEXT UNIQUE,                      -- 登入郵箱
  phone TEXT,                             -- 聯絡電話
  is_active BOOLEAN DEFAULT TRUE,         -- 是否啟用
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- 索引
CREATE INDEX idx_operators_email ON operators(email);
CREATE INDEX idx_operators_active ON operators(is_active);

-- 註解
COMMENT ON TABLE operators IS '客服人員資料表';
COMMENT ON COLUMN operators.operator_id IS '員工編號（唯一識別）';
COMMENT ON COLUMN operators.display_name IS '聊天介面顯示的名稱';
COMMENT ON COLUMN operators.avatar_url IS '個人頭像網址（可空，使用預設）';

-- 插入測試資料
INSERT INTO operators (operator_id, display_name, email) VALUES
  ('admin', '王小明', 'wang@example.com'),
  ('op_001', '李小華', 'li@example.com');
```

#### 2. 新增 API endpoint

**檔案：** `backend/app.py`

```python
from pydantic import BaseModel
from typing import Optional

class OperatorProfile(BaseModel):
    operator_id: str
    display_name: str
    avatar_url: Optional[str] = None
    email: Optional[str] = None
    is_active: bool = True

@app.get("/api/operators/{operator_id}")
def get_operator_profile(operator_id: str):
    """
    取得客服人員資料
    
    使用時機：
    1. 客服登入後載入個人資料
    2. 接手對話前確認資料
    """
    try:
        client = get_supabase_client(prefer_service_role=True)
        
        response = client.table('operators')\
            .select('*')\
            .eq('operator_id', operator_id)\
            .single()\
            .execute()
        
        if not response.data:
            raise HTTPException(status_code=404, detail="操作員不存在")
        
        operator = response.data
        
        # 若未設定個人頭像，使用品牌預設
        if not operator.get('avatar_url'):
            branding = load_branding_config()
            operator['avatar_url'] = branding.get('repair_operator_avatar', 
                                                   '/static/avatars/default_operator.png')
        
        return operator
        
    except HTTPException:
        raise
    except Exception as e:
        logger.error(f"Get operator profile failed: {e}")
        raise HTTPException(status_code=500, detail=str(e))

@app.put("/api/operators/{operator_id}")
def update_operator_profile(operator_id: str, profile: OperatorProfile):
    """
    更新客服人員資料
    
    使用時機：
    1. 客服修改個人顯示名稱
    2. 上傳個人頭像
    """
    try:
        client = get_supabase_client(prefer_service_role=True)
        
        update_data = {
            "display_name": profile.display_name,
            "avatar_url": profile.avatar_url,
            "email": profile.email,
            "updated_at": datetime.utcnow().isoformat()
        }
        
        response = client.table('operators')\
            .update(update_data)\
            .eq('operator_id', operator_id)\
            .execute()
        
        if not response.data:
            raise HTTPException(status_code=404, detail="更新失敗")
        
        return {"status": "ok", "operator": response.data[0]}
        
    except HTTPException:
        raise
    except Exception as e:
        logger.error(f"Update operator profile failed: {e}")
        raise HTTPException(status_code=500, detail=str(e))
```

#### 3. 前端整合

```javascript
// 登入後載入個人資料
async function loadOperatorProfile(operatorId) {
  try {
    const response = await fetch(`/api/operators/${operatorId}`);
    if (!response.ok) {
      throw new Error('載入失敗');
    }
    
    const operator = await response.json();
    
    // 儲存到全域變數
    window.currentOperator = {
      operator_id: operator.operator_id,
      display_name: operator.display_name,
      avatar_url: operator.avatar_url,
      email: operator.email
    };
    
    // 更新 UI
    document.getElementById('operator-name-display').textContent = operator.display_name;
    document.getElementById('operator-avatar-display').src = operator.avatar_url;
    
    return operator;
    
  } catch (error) {
    console.error('載入個人資料失敗:', error);
    alert('無法載入個人資料，請重新登入');
  }
}

// 更新個人資料
async function updateOperatorProfile() {
  const operatorId = window.currentOperator.operator_id;
  const displayName = document.getElementById('operator-name-input').value;
  const avatarUrl = document.getElementById('operator-avatar-input').value;
  
  try {
    const response = await fetch(`/api/operators/${operatorId}`, {
      method: 'PUT',
      headers: {'Content-Type': 'application/json'},
      body: JSON.stringify({
        operator_id: operatorId,
        display_name: displayName,
        avatar_url: avatarUrl,
        email: window.currentOperator.email,
        is_active: true
      })
    });
    
    if (!response.ok) {
      throw new Error('更新失敗');
    }
    
    alert('✅ 個人資料已更新');
    await loadOperatorProfile(operatorId);  // 重新載入
    
  } catch (error) {
    console.error('更新失敗:', error);
    alert('更新失敗：' + error.message);
  }
}

// 接手對話時使用資料庫資料
```

## 🎯 方案三：混合版（推薦）

### 設計思路
- **短期：** 使用方案一（localStorage + 統一頭像）
- **長期：** 逐步遷移到方案二（資料庫 + 個人頭像）

### 實作步驟

#### 階段 1：使用 localStorage（立即可用）
1. 客服在個人設定頁面輸入名稱
2. 使用品牌配置的統一頭像
3. 接手時從 localStorage 讀取資料

#### 階段 2：建立資料庫表（Phase 5）
1. 建立 `operators` 資料表
2. 新增 API：`GET/PUT /api/operators/{operator_id}`
3. 前端優先從 API 取得資料，失敗則降級到 localStorage

#### 階段 3：實作圖片上傳（Phase 6）
1. 新增圖片上傳 API
2. 前端支援上傳個人頭像
3. 落差時使用品牌預設頭像

### 相容性處理

```javascript
// 統一的客服資料取得函數（支援兩種來源）
async function getOperatorInfo() {
  // 優先嘗試從 API 取得
  try {
    const storedId = localStorage.getItem('operator_id');
    if (storedId) {
      const response = await fetch(`/api/operators/${storedId}`);
      if (response.ok) {
        const operator = await response.json();
        return {
          operator_id: operator.operator_id,
          operator_name: operator.display_name,
          operator_avatar: operator.avatar_url
        };
      }
    }
  } catch (error) {
    console.warn('API 取得失敗，降級到 localStorage:', error);
  }
  
  // 降級：從 localStorage 取得
  const profile = JSON.parse(localStorage.getItem('operator_profile') || '{}');
  const brandingResponse = await fetch('/api/branding');
  const branding = await brandingResponse.json();
  
  return {
    operator_id: profile.id || 'admin',
    operator_name: profile.name || '客服人員',
    operator_avatar: profile.avatar || 
                     branding.repair_operator_avatar || 
                     '/static/avatars/default_operator.png'
  };
}
```
