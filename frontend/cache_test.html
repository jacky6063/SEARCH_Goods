🔧 快取清除驗證頁面

正在檢查 escapeHtml 函數...

步驟 1：立即檢查

步驟 2：強制清除快取（必做）

方法 A：使用快捷鍵（推薦）

  • Mac: 按住 Cmd + Shift + R
  • Windows: 按住 Ctrl + Shift + R
  • 或 Cmd/Ctrl + Shift + Delete 開啟清除資料對話框

方法 B：使用開發者工具

  1. 按 F12 開啟開發者工具
  2. 右鍵點擊重新整理按鈕
  3. 選擇「清空快取並強制重新整理」

方法 C：禁用快取（開發時使用）

  1. 按 F12 開啟開發者工具
  2. 切換到 Network 標籤
  3. 勾選「Disable cache」
  4. 保持開發者工具開啟狀態

步驟 3：重新測試

步驟 4：驗證主頁面

在主頁面的 Console 執行以下程式碼：

// 檢查 escapeHtml 函數
console.log('escapeHtml 類型:', typeof escapeHtml);

// 如果顯示 "function" 表示成功
// 如果顯示 "undefined" 表示快取未清除

// 測試函數
if (typeof escapeHtml === 'function') {
  console.log('✅ 測試:', escapeHtml('<test>'));
} else {
  console.log('❌ 函數不存在，請清除快取！');
}
