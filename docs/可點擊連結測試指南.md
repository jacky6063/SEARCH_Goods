## ⚠️ 常見問題排查

### 問題 1: 按鈕沒有顯示

**可能原因**：
- 後端未返回 `rich_content`
- 前端未正確提取 `data.rich_content`

**檢查方法**：
1. 開啟瀏覽器開發者工具（F12）
2. 切換到 Network 標籤
3. 送出查詢後檢查 `/api/chat` 回應
4. 確認有 `rich_content` 欄位

**解決方案**：
```bash
# 檢查後端日誌
cd backend
tail -f logs/app.log | grep "rich_content"
```

---

### 問題 2: 按鈕可見但無法點擊

**可能原因**：
- `action` 欄位為空
- CSS `pointer-events: none`
- JavaScript 事件被攔截

**檢查方法**：
1. 右鍵點擊按鈕 → 檢查元素
2. 查看 `<a>` 標籤的 `href` 屬性
3. 檢查 computed styles 中的 `pointer-events`

**解決方案**：
```javascript
// 在瀏覽器 Console 測試
document.querySelectorAll('.rich-action-btn').forEach(btn => {
  console.log('按鈕 href:', btn.href);
});
```

---

### 問題 3: 電話連結在桌面無反應

**這是正常的！** 

- 電話連結 (`tel:`) 在桌面瀏覽器通常不會有動作
- 需要在手機上測試
- 可以檢查連結是否正確生成

**驗證方法**：
```javascript
// Console 檢查
const phoneBtn = document.querySelector('a[href^="tel:"]');
console.log(phoneBtn ? '電話連結存在' : '電話連結缺失');
console.log('連結:', phoneBtn?.href);
```

---

### 問題 4: Google Maps 連結錯誤

**可能原因**：
- 地址 URL 編碼錯誤
- Maps API 參數格式錯誤

**檢查方法**：
```python
# 後端測試
import urllib.parse

address = "台中市河南路二段 262 號 3 樓之 11"
encoded = urllib.parse.quote(f"{address} 傳啟資訊")
maps_url = f"https://www.google.com/maps/search/?api=1&query={encoded}"
print(maps_url)

# 應輸出：
# https://www.google.com/maps/search/?api=1&query=%E5%8F%B0%E4%B8%AD...
```

**解決方案**：
確認 `company_response_formatter.py` 中的編碼邏輯正確
