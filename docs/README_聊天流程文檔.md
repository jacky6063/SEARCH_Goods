## 🔗 核心流程要點

### 三大決策節點

```
🔀 決策 1：快速識別意圖
   ├─ 類目導覽 → L1/L2/L3 列表
   ├─ 概覽問句 → Top-K 分類
   └─ 其他 → 進入 LLM 判讀

🔀 決策 2：對話意圖分類
   ├─ information → 資訊回答
   ├─ product_search → 商品搜尋
   ├─ event_food_planning → 活動策劃
   └─ general → 一般對話

🔀 決策 3：商品搜尋優先級
   ├─ L1/L2/L3 分類層級搜尋 (最優)
   ├─ 模糊搜尋 (名稱/描述/分類)
   ├─ 結構化篩選 (必須詞/排除詞/價格)
   ├─ 嚴格搜尋 (備用)
   └─ 關鍵詞篩選 (最後)
```

### 四大核心步驟

```
Step 1️⃣: llm_analyze_query() [llm_service.py:1740]
   └─ LLM 分析查詢，提取 L1/L2/L3 分類層級

Step 2️⃣: _detect_conversation_intent() [llm_service.py:1570]
   └─ 分類對話意圖 (information/product_search/event/general)

Step 3️⃣: _search_products_for_chat() [llm_service.py:1254]
   └─ 多層商品搜尋 (5 層優先級)

Step 4️⃣: _mock_or_real_llm() [llm_service.py:1486]
   └─ LLM 或 Mock 生成自然回覆
```
