## 2025-10-23 — Chat Mode ⇄ Search Mode 整合任務卡

### 任務摘要
- 扩充現有系統，讓 **聊天模式（Chat Mode）** 支援自然語言互動並回傳多組商品群組。
- 切換到 **商品模式（Search Mode）** 時，必須自動載入並顯示聊天模式找出的全部商品，維持兩種模式資料一致。

### 前端需求重點
1. **ChatView**
   - 聊天視窗顯示 `groups[]` 分群結果，每組需有分類標題與商品卡。
   - 若僅有 `items[]`，沿用單組商品卡顯示。
   - 提供「切換至商品模式」按鈕，並保留存在的語音、重置功能。
2. **SearchView**
   - 接收聊天模式回傳的所有商品（多群組合併後清單）。
   - 切換後自動呈現 10 項商品（例示：餅乾 3 + 飲料 3 + 休閒食品 4）。
   - 仍需保留原有搜尋欄位、篩選與排序行為。

### 後端需求重點
- 新增或擴充 `/api/chat-search` 以支援自然語言解析並回傳統一格式：
  ```json
  {
    "reply": "…",
    "groups": [
      {"category": "餅乾類", "items": [...]},
      {"category": "飲料類", "items": [...]}
    ],
    "related_queries": ["..."]
  }
  ```
- 單群組情境以 `items[]` 回傳。
- 查無結果時提供提示訊息與 `related_queries` 建議。
- 資料來源固定為 `VIEW_GOODS.csv`，需運用欄位：`GoodIden`, `Name`, `Description`, `Price`, `SpecialOffer`, `Category`, `Goods_link1`, `Goodspic_link1`。

### 驗收與體驗指標
| 項目 | 期待結果 |
| --- | --- |
| 聊天畫面 | 支援多群組顯示，含分類標題與商品卡 |
| 商品模式 | 切換後自動顯示聊天結果的全部商品（合併列表） |
| API | 回傳 `reply + groups/items + related_queries` 結構正確 |
| 錯誤處理 | 查無結果時提供提示與相關建議 |

## 2025-10-25 — 智慧混合分配系統與前端自動化補丁任務卡

### 任務摘要
- 實現後端 **智慧多分類 Fallback 系統**，支援餅乾+飲料組合查詢的預算約束分配。
- 部署前端 **自動化補丁系統 V4**，提供雙層攔截機制和智慧建議收集功能。
- 整合 **UI 清理系統**，自動移除技術內容提升用戶體驗。

### 後端核心升級 (multi_category_party.py)

#### 智慧混合比例算法
```python
# 基準分配：60% 餅乾 / 40% 飲料
# 動態調整機制：
- 語意加權：根據關鍵字頻率在 ±10% 範圍調整
- 價格修正：均價差距 ≥1.8 倍時向貴的類別 +10%
- 範圍限制：[20%, 80%] 確保平衡推薦
```

#### 貪婪裝配優化
- **價格升序排列**：優先選擇低價商品最大化數量
- **預算約束**：嚴格防止超支，支援零價商品處理
- **跨類補償**：某類無商品時從另類補滿預算

#### 雙模式運行
- **無預算模式**：展示型推薦（各取8筆精選商品）
- **預算模式**：智慧分配 + 貪婪裝配算法

### 前端自動化補丁系統 V4

#### auto_fetch_tap_v4.js - 雙層攔截架構
- **Fetch 層**：自動保存 `/api/chat` 回應內容到 `window.lastAssistantJson`
- **UI 層**：同時攔截 `submit` 和 `keydown` 事件捕獲同意詞
- **即時響應**：用戶輸入同意詞立即觸發搜尋，無需等待 API

#### original_suggestion_all.js - 智慧建議收集
- **全面 ID 收集**：從多種 JSON 結構掃描（groups, categories, items, recommendations）
- **多觸發支援**：點擊「1.原建議」+ 輸入同意詞（要/OK/1/需要等）
- **容錯設計**：限制最多60筆商品，避免系統負載過重

#### suppress_hidden_json.js - UI 清理系統
- **即時清理**：移除界面中的隱藏 JSON 內容 `（隱藏JSON：...）`
- **動態監控**：MutationObserver 實時清理新增內容
