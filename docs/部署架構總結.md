## 🏗️ 當前架構

### 後端 (Backend)
- **平台**: Render
- **部署方式**: GitHub Actions 自動觸發
- **觸發條件**: 推送到 `main` 分支
- **流程**:
  ```
  Git Push → 測試 (pytest) → Docker 建置 → Render 部署
  ```
- **預計時間**: 10-15 分鐘
- **監控**: 
  - GitHub Actions: https://github.com/jacky6063/SEARCH_Goods/actions
  - Render Dashboard: https://dashboard.render.com/

### 前端 (Frontend)
- **類型**: 靜態 HTML 檔案
- **位置**: `frontend/index.html`
- **部署方式**: 無需部署，直接從倉庫使用
- **更新方式**: 推送到 GitHub 後即時可用
- **注意事項**: 
  - 用戶需清除瀏覽器快取查看更新
  - 使用 `Cmd+Shift+R` 強制重新載入

## 🚀 部署流程

### 標準部署步驟

```bash
# 1. 提交代碼
git add -A
git commit -m "你的提交訊息"
git push origin main

# 2. 等待部署（10-15 分鐘）
# GitHub Actions 會自動執行：
# - 後端測試
# - Docker 映像建置
# - Render 部署

# 3. 驗證部署
# 檢查 GitHub Actions 狀態
# 確認 Render 服務已更新
```

## 🧪 測試流程

### 部署後測試

1. **等待部署完成**（15 分鐘）

2. **清除瀏覽器快取** ⚠️ 重要
   ```
   Chrome/Edge: Cmd+Shift+Delete
   Safari: Cmd+Option+E
   強制重新載入: Cmd+Shift+R
   ```

3. **驗證前端版本**
   ```javascript
   // 在瀏覽器 Console 執行
   document.querySelector('head').innerHTML.includes('2025-11-09')
   // 應返回 true
   ```

4. **測試功能**
   ```
   輸入: 公司電話是多少？
   預期: 看到可點擊的按鈕（電話、地址、網站）
   ```

5. **檢查 Console**
   ```
   應看到: 🔍 [DEBUG] 和 🎨 [DEBUG] 日誌
   ```

## ⚠️ 常見問題

### Q1: 前端沒有更新
**A**: 清除瀏覽器快取
- 這是最常見的問題
- 90% 的情況都是快取造成
- 解決方法：`Cmd+Shift+Delete` + 完全關閉瀏覽器

### Q2: 後端部署失敗
**A**: 檢查 GitHub Actions 日誌
1. 前往 Actions 頁面
2. 查看失敗的 workflow
3. 檢查測試或建置錯誤
4. 修復後重新推送

### Q3: 按鈕沒有顯示
**A**: 按順序檢查
1. 版本是否正確（2025-11-09）
2. Console 是否有 DEBUG 日誌
3. API 是否返回 rich_content
4. 瀏覽器快取是否已清除
