## 🎯 系統概述

SEARCH_Goods 是一個智能商品搜尋與聊天系統，整合了自然語言處理、產品推薦和電商功能。

**最新擴充：** 🏠 住宅維修問題回覆客服系統（2025年11月新增）

### 主要功能模組

#### 1. 商品搜尋系統
- 🤖 **智能對話**: 基於 OpenAI GPT 的自然語言理解
- 🔍 **上下文搜尋**: 從對話歷史中提取產品意圖
- 💡 **個性化推薦**: 根據用戶偏好智能推薦商品
- 📱 **響應式設計**: 支援桌面與行動裝置
- 🚀 **漸進式降級**: 多層次查詢策略確保系統穩定性

#### 2. 住宅維修客服系統 ✨ NEW
- 🔧 **維修諮詢**: 自然語言維修問題診斷
- 📋 **專業指引**: 標準化檢查方法和處理建議 (SOP)
- 🎥 **影音教學**: 整合 YouTube 影片說明
- 🔗 **快速報修**: 一鍵連結線上報修系統
- 🏘️ **責任判定**: 區分住家/共用部分責任歸屬

### 技術棧
- **後端**: FastAPI + Python 3.8+
- **前端**: 原生 HTML/CSS/JavaScript (SPA)
- **AI 服務**: OpenAI GPT-4o-mini
- **資料存儲**: 
  - 商品資料：CSV 檔案 + 記憶體快取
  - 維修資料：CSV 檔案（40+ 維修項目）✨
- **部署**: Docker + Render (後端) + Netlify (前端)

### 資料來源
- **商品資料庫**: `data/VIEW_GOODS_enhanced.csv`
- **維修知識庫**: `data/集合式住宅報修資料.csv` ✨
  - 40 筆維修項目
  - 12 個維修類別
  - 包含專業檢查方法和處理建議 (SOP)
  - 整合報修連結和影片教學

## 🔄 資料流程

### 1. 用戶查詢流程
```
用戶輸入 → 前端驗證 → API路由 → 意圖分析 → 業務處理 → 結果回傳
```

### 2. 聊天對話流程
```
對話輸入 → 上下文檢測 → LLM處理 → 商品匹配 → 結構化回應 → 前端展示
```

### 3. 商品搜尋流程
```
搜尋查詢 → 關鍵字解析 → 資料篩選 → 評分排序 → 結果格式化 → 用戶展示
```

## 🔧 核心功能

### 智能對話系統
- **上下文感知**: 從對話歷史中提取產品意圖
- **意圖分類**: 區分資訊諮詢、產品搜尋、一般對話
- **置信度評估**: 根據用戶表達的明確程度調整回應策略
- **個性化語調**: 針對不同類型問題採用相應的回應風格

### 商品推薦引擎
- **多層次搜尋**: LLM智能搜尋 → 規則式後備 → 基本關鍵字匹配
- **評分機制**: 名稱匹配(+2) + 描述匹配(+1) + 分類匹配(+1) + 特價加分(+0.2)
- **結果優化**: 自動生成行銷文案、價格突出顯示、智能排序

### 會話管理系統
- **狀態追蹤**: 會話ID追蹤用戶互動脈絡
- **快取策略**: 分層快取提升回應速度
- **降級處理**: 系統故障時自動使用簡化功能
