### 5. **錯誤排查指引**

#### **問題 A: 找不到公司簡介檔案**

**日誌訊息**:
```
⚠️ 公司簡介檔案不存在: /app/data/company_profiles/company_profile_chuanchi.jsonl
```

**原因**: `data/company_profiles/` 目錄或檔案未包含在 Docker 映像中

**解決方案**:
1. 檢查 `.dockerignore` 沒有排除 `data/` 目錄
2. 確認 `Dockerfile` 有正確 COPY 資料檔案
3. 重新建置 Docker 映像

---

#### **問題 B: 意圖判斷失敗**

**症狀**: 公司查詢被誤判為商品搜尋

**原因**: 關鍵字匹配優先級問題

**解決方案**:
1. 檢查 `llm_service.py` 的 `COMPANY_INFO_PATTERNS` 是否完整
2. 確認 `_detect_conversation_intent()` 中 company_info 檢查在最前面
3. 測試更多查詢案例

---

#### **問題 C: 回應格式錯誤**

**症狀**: 回應內容不完整或格式異常

**原因**: `company_response_formatter.py` 資料來源欄位不存在

**解決方案**:
1. 檢查 `company_profile_chuanchi.jsonl` 資料完整性
2. 驗證欄位名稱是否正確
3. 查看格式化器的錯誤處理
