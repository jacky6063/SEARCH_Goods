# 📊 分類索引性能演示

## 視覺化對比

### 無索引（舊方式） ❌

```
查詢：L3 = "米類"

DataFrame（953 行商品）
├─ 行 0: L3 = "常溫食品"  🔍 不符
├─ 行 1: L3 = "海鮮"      🔍 不符
├─ 行 2: L3 = "米類"      ✅ 符合！ (第 1 件)
├─ 行 3: L3 = "麵類"      🔍 不符
├─ 行 4: L3 = "蔬菜"      🔍 不符
├─ 行 5: L3 = "米類"      ✅ 符合！ (第 2 件)
├─ ...
└─ 行 952: L3 = "米類"    ✅ 符合！ (第 6 件)

⏱️ 必須逐行掃描 953 次！
💢 耗時：100-200ms
```

### 有索引（新方式） ✅

```
查詢：L3 = "米類"

預建索引
  L3 表 ──────────────────────
  ├─ "米類": {0, 5, 10, 15, ...}  ← O(1) 直接查找！
  ├─ "麵類": {1, 6, 11, 16, ...}
  └─ "蔬菜": {2, 7, 12, 17, ...}

✅ 瞬間獲得行索引集合：{0, 5, 10, 15, 20, ...}
⏱️ 只需要一次哈希表查找！
💨 耗時：5-10ms
```

## 一次查詢的完整時間分解

### 場景：用戶點擊「L3 米類」

#### 🔴 優化前（舊版本）

```
POST /api/search
{query: "", category_hierarchy: {L3: "米類"}}

┌─────────────────────────────────────┐
│ LLM 查詢擴展 (llm_expand_query)    │ 500-800ms ← ❌ 不必要
└─────────────────────────────────────┘
                ↓
┌─────────────────────────────────────┐
│ LLM 意圖分析 (llm_analyze_query)    │ 300-600ms ← ❌ 不必要
└─────────────────────────────────────┘
                ↓
┌─────────────────────────────────────┐
│ search_products() 評分搜尋          │ 100-200ms ← ⚠️ 低效
│ (掃描 953 行商品，計算相關分數)    │
└─────────────────────────────────────┘
                ↓
┌─────────────────────────────────────┐
│ 層級過濾 (逐行掃描)                 │ 100-200ms ← ⚠️ 重複掃描
└─────────────────────────────────────┘
                ↓
┌─────────────────────────────────────┐
│ LLM 重排 (llm_rerank_products)     │ 500-800ms ← ❌ 不必要
└─────────────────────────────────────┘
                ↓
┌─────────────────────────────────────┐
│ 文案生成 (llm_generate_promo)       │ 300-500ms ← ❌ 不必要
└─────────────────────────────────────┘
                ↓
┌─────────────────────────────────────┐
│ 序列化和傳輸                        │ 100-200ms
└─────────────────────────────────────┘

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【總耗時】2-4 秒 ⏱️
【用戶感受】明顯延遲 😞
```

#### 🟢 優化後（新版本）

```
POST /api/search
{query: "", category_hierarchy: {L3: "米類"}, 
 disable_rerank: true, disable_promo: true}

[P0.3] 快取檢查
  ✓ 首次查詢 → 未命中
  ↓ 0-1ms

[P0.1] 快速路徑
  ✓ query 為空 + category_hierarchy 存在
  ✓ 跳過 LLM 擴展和意圖分析 ← ✅ 省 800-1200ms
  ↓ 1-5ms

[P0.1] 返回全數商品
  ✓ df.to_dict(orient="records") → 953 行
  ↓ 5-10ms

[P1.1] 索引查找
  ✓ _category_index["L3"].get("米類")
  ✓ O(1) 直接查找 ← ✅ 比掃描快 90%
  ↓ 10-15ms

[P1.2] 瘦身格式化
  ✓ 只返回 7 個首屏欄位 ← ✅ 省 30-40% 傳輸
  ↓ 15-20ms

[P0.2] 禁用重排和文案
  ✓ disable_rerank=true, disable_promo=true
  ✓ 跳過 800-1300ms ← ✅ 省大時間
  ↓ 20-25ms

[P0.3] 存儲快取
  ✓ TTL 180 秒
  ↓ 25-30ms

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【總耗時】25-30 毫秒 ⚡
【改進】87% 加速 (2-4s → 30ms)
【用戶感受】瞬時反應 ✨
```
