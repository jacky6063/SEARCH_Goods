# 開發環境設置指南

## 🚀 快速開始

### 系統要求
- **Python**: 3.8 或更高版本
- **Node.js**: 14+ (用於前端開發工具，可選)
- **Git**: 版本控制
- **編輯器**: VS Code (推薦) 或其他 Python IDE

### 基本依賴
```bash
# 必要的系統套件
brew install python3 git curl  # macOS
# 或
apt install python3 python3-pip git curl  # Ubuntu/Debian
```

## 📦 專案設置

### 1. 克隆專案
```bash
git clone https://github.com/jacky6063/SEARCH_Goods.git
cd SEARCH_Goods
```

### 2. 後端設置
```bash
# 進入後端目錄
cd backend

# 建立虛擬環境
python3 -m venv .venv

# 啟動虛擬環境
source .venv/bin/activate  # Linux/macOS
# 或
.venv\Scripts\activate     # Windows

# 安裝依賴
pip install -r requirements.txt
```

### 3. 環境變數配置
```bash
# 複製環境變數範本
cp .env.example .env

# 編輯環境變數
nano .env
```

#### 環境變數範例 (`.env`)
```env
# OpenAI API 配置 (如需使用 LLM 功能)
OPENAI_API_KEY=sk-your-openai-api-key-here
OPENAI_MODEL=gpt-4o-mini

# LLM 功能開關
USE_LLM_EXPAND=true
USE_LLM_SHORTDESC=true
USE_LLM_INTENT=true
USE_CHAT_MODE=true

# 搜尋功能 LLM 配置
SEARCH_USE_LLM_EXPAND=true
SEARCH_USE_LLM_SHORTDESC=true
SEARCH_USE_LLM_RERANK=false
SEARCH_USE_LLM_INTENT=true
SEARCH_USE_LLM_PROMO=false

# 聊天功能 LLM 配置  
CHAT_USE_LLM_EXPAND=true
CHAT_USE_LLM_SHORTDESC=true
CHAT_USE_LLM_RERANK=false
CHAT_USE_LLM_INTENT=true
CHAT_USE_LLM_PROMO=false

# 資料檔案路徑
DATA_PATH=../data/VIEW_GOODS_enhanced.csv

# 管理功能
ADMIN_TOKEN=dev-admin-token-123
ALLOW_DEV_ADMIN=1

# 伺服器配置
HOST=0.0.0.0
PORT=8000
```

### 4. 啟動後端服務
```bash
# 開發模式 (自動重載)
uvicorn app:app --reload --host 0.0.0.0 --port 8000

# 或使用 Python 直接執行
python -m uvicorn app:app --reload --host 0.0.0.0 --port 8000
```

### 5. 前端設置
```bash
# 開啟新的終端視窗
cd frontend

# 啟動簡單 HTTP 伺服器
python -m http.server 5173

# 或使用 Node.js (如果有安裝)
npx serve -s . -l 5173
```

### 6. 驗證安裝
開啟瀏覽器訪問：
- **前端**: http://localhost:5173
- **後端 API**: http://localhost:8000/health
- **API 文檔**: http://localhost:8000/docs

## 🧪 測試環境

### 執行單元測試
```bash
cd backend

# 執行所有測試
pytest -v

# 執行特定測試檔案
pytest tests/test_llm_service.py -v

# 執行並生成覆蓋率報告
pytest --cov=. --cov-report=html tests/
```

### 測試資料準備
```bash
# 確保測試資料檔案存在
ls -la ../data/VIEW_GOODS_enhanced.csv

# 如果需要，可以使用範例資料
cp ../data/sample_goods.csv ../data/VIEW_GOODS_enhanced.csv
```

## 🐳 Docker 開發環境

### 使用 Docker Compose
```bash
# 啟動開發環境 (包含即時重載)
docker-compose -f docker-compose.dev.yml up --build

# 後台執行
docker-compose -f docker-compose.dev.yml up -d --build

# 查看日誌
docker-compose -f docker-compose.dev.yml logs -f

# 停止服務
docker-compose -f docker-compose.dev.yml down
```

### Docker 開發配置
`docker-compose.dev.yml` 已配置：
- 程式碼熱重載
- 環境變數注入
- 端口映射 (8000:8000)
- 本地資料卷掛載

## 🔍 開發工作流程

### 1. 日常開發流程
```bash
# 1. 更新程式碼
git pull origin main

# 2. 啟動開發環境
cd backend && source .venv/bin/activate
uvicorn app:app --reload --host 0.0.0.0 --port 8000

# 3. 在另一個終端啟動前端
cd frontend && python -m http.server 5173

# 4. 進行開發...

# 5. 執行測試
cd backend && pytest -v

# 6. 提交更改
git add .
git commit -m "feat: 新增功能描述"
git push origin feature-branch
```

### 2. 功能開發流程
```bash
# 1. 建立功能分支
git checkout -b feature/new-feature

# 2. 開發功能
# ... 編寫程式碼 ...

# 3. 測試功能
pytest tests/test_new_feature.py

# 4. 提交更改
git add .
git commit -m "feat: implement new feature"

# 5. 推送並建立 Pull Request
git push origin feature/new-feature
```

## 🐛 常見問題排解

### 1. Python 虛擬環境問題
```bash
# 如果虛擬環境損壞，重新建立
rm -rf .venv
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. 端口被占用
```bash
# 查找占用端口的程序
lsof -ti:8000
# 終止程序
kill -9 $(lsof -ti:8000)

# 或使用不同端口
uvicorn app:app --reload --port 8001
```

### 3. 模組導入錯誤
```bash
# 設定 Python 路徑
export PYTHONPATH="${PYTHONPATH}:$(pwd)/backend"

# 或在 IDE 中設定工作目錄為 backend/
```

### 4. OpenAI API 問題
```bash
# 檢查 API key 是否正確設定
echo $OPENAI_API_KEY

# 測試 API 連線
python -c "
from openai import OpenAI
client = OpenAI()
try:
    response = client.models.list()
    print('API 連線成功')
except Exception as e:
    print(f'API 連線失敗: {e}')
"
```

### 5. CSV 資料檔案問題
```bash
# 檢查檔案是否存在
ls -la ../data/VIEW_GOODS_enhanced.csv

# 檢查檔案編碼
file -bi ../data/VIEW_GOODS_enhanced.csv

# 如果編碼問題，轉換為 UTF-8
iconv -f big5 -t utf-8 source.csv > ../data/VIEW_GOODS_enhanced.csv
```
