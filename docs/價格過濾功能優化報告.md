# 價格過濾功能問題分析與優化報告

## 問題分析

### 📋 問題描述
用戶查詢「我想要找2500元以下的女用包包」，但系統回傳的商品價格都超過預算：
- 品牌訂製大容量時尚斜背包：**2980元** ❌
- 柔軟手感牛皮前釦式肩背包：**3980元** ❌  
- 格紋裝飾配色兩用後背包：**2980元**（特價2533元）❌
- 手工刺繡旋轉音符三用包：**3480元** ❌

### 🔍 根因分析

經過深入檢查，發現以下核心問題：

1. **缺少價格過濾功能**：
   - `search_ext_goods_1024001.py` 的 `filter_items` 函數完全沒有價格過濾邏輯
   - 只支援類別、關鍵字和排除詞過濾

2. **預算提取功能有限**：
   - `extract_budget_and_cats` 僅支援簡單數字提取
   - 無法識別「2500元以下」、「預算2500」等常見表達方式

3. **LLM 意圖分析不完整**：
   - `_derive_structured_filters` 沒有處理價格/預算相關的結構化過濾

4. **搜尋流程缺失**：
   - 即使提取到預算，也沒有傳遞給搜尋引擎進行過濾

### 2. 實作價格過濾功能

**檔案**：`backend/search_ext_goods_1024001.py`

```python
def filter_items(items: List[Dict[str, Any]],
                 category_filter: Optional[str]=None,
                 must_have_keywords: Optional[List[str]]=None,
                 excluded_keywords: Optional[List[str]]=None,
                 price_filter: Optional[Dict[str, Any]]=None) -> List[Dict[str, Any]]:
    
    # 🆕 價格過濾邏輯
    if price_filter:
        min_price = price_filter.get("min_price")
        max_price = price_filter.get("max_price")
        
        def _price_in_range(item: Dict[str, Any]) -> bool:
            # 優先使用特價，再使用原價
            special_price = FieldAccessor.get_special_price(item)
            regular_price = FieldAccessor.get_price(item)
            effective_price = special_price if special_price and special_price > 0 else regular_price
            
            if not effective_price or effective_price <= 0:
                return False  # 排除無效價格商品
                
            # 檢查價格範圍
            if min_price is not None and effective_price < min_price:
                return False
            if max_price is not None and effective_price > max_price:
                return False
            return True
        
        out = [x for x in out if _price_in_range(x)]
```

## 🔧 技術特色

### 1. 智能價格判斷
- **特價優先**：如果商品有特價，優先使用特價進行判斷
- **價格驗證**：自動排除無效價格（空值、0等）的商品

- 「2500元以下」→ max_price: 2500
