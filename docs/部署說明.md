# 部署說明

## 🚀 部署架構

### 後端 (Backend)
- **平台**: Render
- **部署方式**: GitHub Actions 自動觸發
- **流程**: 推送到 main → 測試 → Docker 建置 → Render 部署
- **預計時間**: 10-15 分鐘

### 前端 (Frontend)
- **部署方式**: 前端不使用自動部署
- **說明**: 前端為靜態 HTML 檔案，直接從倉庫使用

---

## 📋 部署步驟

### 1. 推送代碼
```bash
git add -A
git commit -m "你的提交訊息"
git push origin main
```

### 2. 監控部署狀態

#### 後端 (Render)
- GitHub Actions: https://github.com/jacky6063/SEARCH_Goods/actions
- Render Dashboard: https://dashboard.render.com/

---

## ⏰ 預期時間軸

```
推送代碼
    ↓
    └─ 後端 (Render):  10-15 分鐘 ✅ GitHub Actions

總計: 約 15 分鐘
```

**建議**: 等待 **15 分鐘**後再測試

## 🔍 驗證功能

### 測試可點擊連結

1. **聯絡資訊查詢**
   ```
   輸入: 公司電話是多少？
   預期: 看到可點擊的電話、地址、網站按鈕
   ```

2. **促銷活動查詢**
   ```
   輸入: 有什麼優惠活動？
   預期: 看到可點擊的產品連結和影片按鈕
   ```

3. **檢查 Console 日誌**
   - 應該看到 `🔍 [DEBUG]` 開頭的日誌
   - 確認 `rich_content` 被正確處理

## ⚠️ 常見問題

### Q1: 後端更新但前端沒更新
**A**: 檢查前端檔案
1. 確認 `frontend/index.html` 已更新
2. 清除瀏覽器快取
3. 使用無痕模式測試

### Q2: 如何檢查後端部署狀態
**A**: 查看 Render 日誌
1. 登入 Render Dashboard
2. 選擇你的服務
3. 查看 "Events" 或 "Logs" 標籤

## 📊 部署檢查清單

部署完成後，請確認：

- [ ] GitHub Actions 測試通過 (綠色勾勾)
- [ ] Render 部署成功 (後端 API 可訪問)
- [ ] 清除瀏覽器快取
- [ ] 前端版本正確 (2025-11-09)
- [ ] Console 有 DEBUG 日誌
- [ ] 聊天回應有可點擊按鈕
- [ ] 電話按鈕可點擊
- [ ] 地址按鈕開啟 Google Maps
- [ ] 網址按鈕開啟新分頁
