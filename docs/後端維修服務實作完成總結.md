### 2. API 端點

#### 在 `backend/app.py` 新增 3 個端點

**1. `POST /api/repair/chat`** - 維修聊天端點
- 請求參數: `message`, `history`, `session_id`, `topn`
- 回應內容: `reply`, `repairs`, `session_id`, `meta`
- 功能: 結合搜尋 + LLM 生成自然對話

**2. `POST /api/repair/search`** - 純搜尋端點
- 請求參數: `query`, `topn`, `category`
- 回應內容: `results`, `meta`
- 功能: 不含對話生成的快速搜尋

**3. `GET /api/repair/categories`** - 取得維修類別
- 回應內容: `categories` 列表
- 功能: 提供前端分類篩選選項

## 🚀 啟用步驟

### 方式一：本地開發

```bash
# 1. 編輯 .env 檔案
echo "ENABLE_REPAIR_SERVICE=True" >> backend/.env
echo "OPENAI_API_KEY=sk-xxx" >> backend/.env

# 2. 重啟服務
cd backend
uvicorn app:app --reload --host 0.0.0.0 --port 8000

# 3. 測試端點
curl http://localhost:8000/api/repair/categories
```

### 方式二：Docker

```yaml
# docker-compose.yml
services:
  backend:
    environment:
      - ENABLE_REPAIR_SERVICE=true
      - OPENAI_API_KEY=${OPENAI_API_KEY}
```
