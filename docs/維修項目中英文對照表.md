## API 端點對照

| 功能 | 中文名稱 | 端點路徑 | HTTP 方法 |
|-----|---------|----------|-----------|
| 取得分類列表 | 維修項目分類 | `/api/repair/categories` | GET |

## API 欄位對照

### 搜尋請求欄位 (Search Request)

| 中文 | 英文 | 資料類型 | 必填 | 說明 |
|-----|------|----------|------|------|
| 查詢字串 | query | string | ✅ | 使用者輸入的問題描述 |
| 責任類型 | responsibility_type | string | ❌ | 住家/共用部分 |
| 類別 | category | string | ❌ | 維修項目類別 |
| 回傳數量 | limit | integer | ❌ | 最多回傳幾筆結果 (預設5) |

### 搜尋回應欄位 (Search Response)

| 中文 | 英文 | 資料類型 | 說明 |
|-----|------|----------|------|
| 成功標記 | ok | boolean | API 呼叫是否成功 |
| 查詢字串 | query | string | 原始查詢字串 |
| 結果列表 | results | array | 匹配的維修項目列表 |
| 總數 | total | integer | 匹配到的項目總數 |

### 聊天請求欄位 (Chat Request)

| 中文 | 英文 | 資料類型 | 必填 | 說明 |
|-----|------|----------|------|------|
| 訊息 | message | string | ✅ | 使用者的訊息 |
| 會話 ID | session_id | string | ✅ | 會話識別碼 |
| 歷史記錄 | history | array | ❌ | 對話歷史 |

### 聊天回應欄位 (Chat Response)

| 中文 | 英文 | 資料類型 | 說明 |
|-----|------|----------|------|
| 成功標記 | ok | boolean | API 呼叫是否成功 |
| 回覆內容 | reply | string | 系統的回覆訊息 |
| 匹配項目 | matched_repairs | array | 匹配到的維修項目 |
| 建議問題 | suggestions | array | 建議的後續問題 |
| 會話 ID | session_id | string | 會話識別碼 |

## 狀態碼對照 (Status Codes)

| 狀態碼 | 英文 | 中文 | 說明 |
|--------|------|------|------|
| 200 | OK | 成功 | 請求成功 |
| 400 | Bad Request | 錯誤的請求 | 請求參數錯誤 |
| 404 | Not Found | 找不到資源 | 請求的資源不存在 |
| 500 | Internal Server Error | 伺服器錯誤 | 伺服器內部錯誤 |

---

## 錯誤訊息對照

| 英文訊息 | 中文訊息 | 說明 |
|---------|----------|------|
| Query is required | 查詢字串為必填欄位 | 未提供查詢字串 |
| Invalid category | 無效的分類 | 指定的分類不存在 |
| No results found | 查無相關維修項目 | 沒有匹配的結果 |
| Session expired | 會話已過期 | 需要重新開始對話 |
| Service unavailable | 服務暫時無法使用 | 系統維護中或故障 |
