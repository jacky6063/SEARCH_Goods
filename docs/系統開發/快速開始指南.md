
## 🎓 核心概念

### 1. 三層級分類

```
大分類 (L1)              中分類 (L2)        小分類 (L3)
├─ 食品                 ├─ 調味品          ├─ 橄欖油
│                       ├─ 烹飪油          └─ 葡萄籽油
│                       └─ 穀物            └─ 米
├─ 飲品                 ├─ 果汁
│                       └─ 咖啡
└─ 日用品               ├─ 清潔用品
                        └─ 護膚品
```

### 2. 搜尋流程

```
用戶查詢: "我想找食品類的調味品"
    ↓
LLM 分析 (llm_analyze_query)
    ↓
識別: L1="食品", L2="調味品", L3=""
    ↓
多層級過濾:
  ├─ L1 過濾 (食品) → 1500 商品
  ├─ L2 過濾 (調味品) → 300 商品
  └─ 排序與評分 → Top 10
    ↓
返回結果 + 分類信息 + 信心度
```

### 3. 信心度指標

```
信心度 ≥ 80% (綠色 🟢)   → 高度相關，值得信賴
信心度 60-79% (黃色 🟡) → 中等相關，可接受
信心度 < 60% (紅色 🔴)  → 低度相關，需謹慎
```

### 任務 4: 測試 LLM 功能

```python
# test_llm.py

import requests
import json

def test_llm_classification():
    """測試 LLM 分類識別"""
    
    response = requests.post(
        "http://localhost:8000/api/chat",
        json={
            "user_message": "我想找食品類的調味品",
            "history": [],
            "catalog": []
        }
    )
    
    data = response.json()
    
    # 驗證分類信息
    assert "category_hierarchy" in data
    assert data["category_hierarchy"]["L1"] == "食品"
    assert data["category_hierarchy"]["L2"] == "調味品"
    
    # 驗證結果
    assert "overview" in data
    assert "results" in data["overview"]
    assert len(data["overview"]["results"]) > 0
    
    # 驗證每個結果都有分類信息
    for item in data["overview"]["results"]:
        assert "hierarchy_score" in item
        assert "matched_levels" in item
    
    print("✅ LLM 分類識別測試通過")

if __name__ == "__main__":
    test_llm_classification()
```

運行測試:

```bash
python test_llm.py
# ✅ LLM 分類識別測試通過
```

## 🐛 常見問題

### Q1: 分類信息未顯示？

**A**: 檢查以下項目：

```bash
# 1. CSV 列名是否正確
head -1 data/VIEW_GOODS_enhanced.csv | grep "CateName_L"

# 2. LLM 是否啟用
echo $OPENAI_API_KEY

# 3. 後端日誌
docker compose logs app | grep "category_hierarchy"
```

### Q2: 搜尋速度慢？

**A**: 可能的原因和解決方案：

```bash
# 1. 檢查 LLM API 響應時間
curl -w "Total time: %{time_total}\n" \
  -X POST http://localhost:8000/api/chat \
  -d "{...}"

# 2. 檢查 CSV 大小
du -h data/VIEW_GOODS_enhanced.csv

# 3. 考慮使用快取或分片
```

### Q3: OpenAI API 調用失敗？

**A**: 檢查 API Key 和配額：

```bash
# 1. 驗證 API Key 格式
echo $OPENAI_API_KEY | head -c 10
# 應輸出: sk-...

# 2. 檢查配額 (訪問 https://platform.openai.com/account/billing)

# 3. 檢查網絡連接
curl https://api.openai.com

# 4. 查看詳細錯誤
docker compose logs app | tail -50
```
