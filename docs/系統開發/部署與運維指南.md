```

Python: 3.8+
Node.js: 14+ (可選，前端開發)
```

### 依賴檢查


```json

  "CateName_L3": "小分類名稱"
```

驗證命令:

```bash
# 查看 CSV 列名
head -1 data/VIEW_GOODS_enhanced.csv

# 應包含: CateName_L1, CateName_L2, CateName_L3
```

## 本地開發

### 快速啟動 (3 分鐘)

```bash
# 1. 進入項目目錄
cd /Users/huangchangchi/Documents/SEARCH_Goods

# 2. 啟動後端
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app:app --reload --host 0.0.0.0 --port 8000

# 3. 新開終端，啟動前端
cd frontend
python -m http.server 5173

# 4. 訪問應用
# 打開瀏覽器: http://localhost:5173
```

### 開發環境配置

**後端 `.env` 文件**:

```bash
# backend/.env

# LLM 功能開關
USE_LLM_EXPAND=True          # 查詢擴展
USE_LLM_SHORTDESC=True       # 生成短描述
USE_LLM_RERANK=False         # 結果重排序
USE_LLM_INTENT=True          # 意圖識別 (含分類)
USE_LLM_PROMO=False          # 營銷內容

# OpenAI 配置
OPENAI_API_KEY=sk-...        # 替換為實際的 API Key
OPENAI_MODEL=gpt-3.5-turbo   # 或 gpt-4

# 開發配置
ALLOW_DEV_ADMIN=1            # 開發環境允許 Admin 操作
DEBUG=True

# 數據路徑
DATA_PATH=../data
```

**複製配置文件**:

```bash
cp backend/.env.example backend/.env
# 編輯 backend/.env，設置 OPENAI_API_KEY
```

## 生產部署

### Docker 部署 (推薦)

#### 方法 1: Docker Compose

```bash
# 生產環境配置
docker compose -f docker-compose.yml up -d

# 驗證容器運行
docker ps
# 應看到 search_goods 容器

# 查看日誌
docker compose logs -f app
```

#### 方法 2: Kubernetes (進階)

```yaml
# k8s-deployment.yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: search-goods
spec:
  replicas: 3
  selector:
    matchLabels:
      app: search-goods
  template:
    metadata:
      labels:
        app: search-goods
    spec:
      containers:
      - name: app
        image: search-goods:latest
        ports:
        - containerPort: 8000
        env:
        - name: OPENAI_API_KEY
          valueFrom:
            secretKeyRef:
              name: openai-secret
              key: api-key
        resources:
          requests:
            memory: "256Mi"
            cpu: "250m"
          limits:
            memory: "512Mi"
            cpu: "500m"
```

### 手動部署

```bash
# 1. 克隆倉庫
git clone https://github.com/jacky6063/SEARCH_Goods.git
cd SEARCH_Goods

# 2. 設置後端
cd backend
```

## 故障排查

### 常見問題

#### 1. 後端無法啟動

**症狀**: `uvicorn app:app --reload` 返回錯誤

**診斷**:

```bash
# 檢查 Python 版本
python3 --version

# 檢查依賴安裝
pip list | grep fastapi

# 檢查 CSV 文件
ls -l data/VIEW_GOODS_enhanced.csv

# 檢查端口占用
lsof -i :8000
```

**解決**:

```bash
# 更新依賴
pip install -r backend/requirements.txt --upgrade

# 使用不同端口
uvicorn app:app --reload --port 8001

# 清理快取
rm -rf backend/__pycache__ backend/.mypy_cache
```

#### 2. LLM 功能不可用

**症狀**: 分類信息未顯示，返回 "分類不可用"

**診斷**:

```bash
# 檢查 OpenAI API Key
echo $OPENAI_API_KEY

# 測試 OpenAI 連接
python3 -c "
import openai
openai.api_key = 'sk-...'
openai.Model.list()
"

# 檢查日誌
docker compose logs app | grep "LLM\|OpenAI"
```

**解決**:

```bash
# 1. 設置正確的 API Key
export OPENAI_API_KEY=sk-YOUR_KEY_HERE

# 2. 檢查 API 配額 (https://platform.openai.com/account/billing)

# 3. 重啟服務
docker compose restart

# 4. 測試 LLM 功能
curl -X POST http://localhost:8000/api/chat \
  -H "Content-Type: application/json" \
  -d '{"user_message":"找食品","history":[],"catalog":[]}'
```

#### 3. CSV 上傳失敗

**症狀**: "上傳失敗" 或 "權限拒絕"

**診斷**:

```bash
# 檢查數據目錄
ls -ld data/
stat data/VIEW_GOODS_enhanced.csv

# 檢查文件編碼
file data/VIEW_GOODS_enhanced.csv
```

**解決**:

```bash
# 設置目錄權限
chmod 755 data/
chmod 644 data/VIEW_GOODS_enhanced.csv

# 確保 CSV 是 UTF-8 編碼
iconv -f ISO-8859-1 -t UTF-8 input.csv > output.csv

# 驗證列名
python3 -c "
import pandas as pd
df = pd.read_csv('data/VIEW_GOODS_enhanced.csv')
print('列名:', df.columns.tolist())
print('包含 L1/L2/L3:', all(x in df.columns for x in ['CateName_L1', 'CateName_L2', 'CateName_L3']))
"
```

#### 4. 前端無法連接後端

**症狀**: 無法加載商品、聊天無反應

**診斷**:

```bash
# 檢查後端運行
curl -v http://localhost:8000/health

# 檢查前端配置
grep -r "API" frontend/index.html | head -3

# 檢查瀏覽器控制台 (F12 → Console)
# 應看到 API 調用日誌或錯誤信息
```

**解決**:

```bash
# 1. 確保後端在運行
docker compose ps

# 2. 檢查防火牆
sudo ufw allow 8000/tcp

# 3. 清除瀏覽器快取
# 按 Cmd+Shift+Delete (Mac) 或 Ctrl+Shift+Delete (Windows)

# 4. 檢查 CORS 設置 (app.py)
# 應包含 allow_origins=["*"]
```

### 關鍵指標

```python
# 在應用中添加監控

import time
from functools import wraps

class Metrics:
    def __init__(self):
        self.requests = 0
        self.errors = 0
        self.total_time = 0
    
    def record_request(self, func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            start = time.time()
            try:
                result = func(*args, **kwargs)
                self.requests += 1
                return result
            except Exception as e:
                self.errors += 1
                raise
            finally:
                self.total_time += time.time() - start
        return wrapper
    
    def get_stats(self):
        return {
            "total_requests": self.requests,
            "total_errors": self.errors,
            "error_rate": self.errors / max(self.requests, 1) * 100,
            "avg_response_time": self.total_time / max(self.requests, 1)
        }

metrics = Metrics()

# 使用示例
@metrics.record_request
def search_products(query):
    # ...
    pass

# 查看統計
print(metrics.get_stats())
```
