```python
synonyms = _CATEGORY_SYNONYMS_CACHE
```

### 容錯機制

```python
# 多層防禦
if not hierarchy or not any(hierarchy.get(k) for k in ["L1", "L2", "L3"]):
    # 層級不完整，進行關鍵字搜尋
    use_keyword_search = True

if hierarchy_results is None or len(hierarchy_results) == 0:
    # 層級搜尋無結果，回退關鍵字
    use_keyword_search = True

if use_keyword_search:
    # 執行備選方案
    results = search_products(query, topn=topn)
```

## 性能考量

### 複雜度分析

| 操作 | 時間複雜度 | 空間複雜度 | 備註 |
|------|-----------|-----------|------|
| 提取分類 | O(n) | O(m) | n=商品數，m=分類數 |
| LLM 分析 | O(1) | O(1) | 不依賴數據規模 |
| L1 過濾 | O(n) | O(1) | 字符串匹配 |
| L2 過濾 | O(k) | O(1) | k≤n (已過濾) |
| L3 過濾 | O(j) | O(1) | j≤k (已過濾) |
| **總計** | **O(n)** | **O(m)** | 支援 10K+ 商品 |

### 快取效率

```
首次調用時間線:
├─ 模組加載
│  ├─ _extract_category_synonyms() ... 100ms
│  └─ _CATEGORY_SYNONYMS_CACHE = {...}
│
├─ 用戶查詢
│  ├─ llm_analyze_query() ............ 2000ms (OpenAI)
│  ├─ _search_by_category_hierarchy() . 50ms (快取命中)
│  └─ 總耗時 ........................ 2050ms
│
└─ 後續查詢
   ├─ llm_analyze_query() ............ 2000ms (無快取)
   ├─ _search_by_category_hierarchy() . 30ms (快取命中)
   └─ 總耗時 ........................ 2030ms
```
