# 商品編號搜尋優化報告

## 📋 優化摘要

**實施日期**: 2025年10月30日  
**問題**: 商品編號查詢（如 `V37312T-0819`）無法正確匹配，系統返回其他不相關商品  
**解決方案**: 在保持智能搜尋平衡的前提下，為商品編號查詢增加精確匹配優先級

## 🎯 優化目標

### 主要目標
1. **修復商品編號搜尋問題** - 確保 `V37312T-0819` 等商品編號能精確匹配
2. **保持智能搜尋平衡** - 不影響現有的自然語言搜尋功能
3. **向後相容性** - 所有現有功能保持正常運作

### 次要目標
1. 支援多種商品編號格式（字母數字組合、純數字條碼等）
2. 提供不區分大小寫的匹配
3. 完整的測試覆蓋率

## 🔧 技術實現

### 1. 商品編號檢測功能
```python
def _is_product_id_query(query: str) -> bool
```

**檢測規則**：
- 長度範圍：6-25 字符
- 格式支援：
  - 字母數字混合格式：`V37312T-0819`, `W80414-S`
  - 純數字條碼格式：`4711467470256` (10-15位)
  - 混合分隔符格式：`ABC123-DEF456`
- 排除條件：包含中文字符、過短或過長的字串

### 2. 精確匹配功能
```python
def _find_exact_product_id_match(df: pd.DataFrame, query: str) -> List[Dict[str, Any]]
```

**匹配邏輯**：
- 檢查 `GoodIden` 欄位的完全匹配
- 不區分大小寫比較
- 支援多個商品編號欄位名稱

### 3. 優化評分機制
```python
def score_row(row: Dict[str, Any], terms: List[str], original_query: str = "") -> float
```

**評分策略**：
- 商品編號精確匹配：50.0 分（最高優先級）
- 原有智能搜尋：1.0-2.5 分（保持不變）
- 確保精確匹配始終排在最前面

### 4. 搜尋流程優化
```python
def search_products(...) -> Tuple[list[dict], List[str]]
```

**優化流程**：
1. 檢測是否為商品編號查詢
2. 如果是，優先執行精確匹配
3. 找到精確匹配則直接返回
4. 否則回退到原有智能搜尋
