# 價格篩選解析指南

本文件說明聊天商品搜尋中「價格 / 預算」相關語句的解析與篩選邏輯，協助產品與開發快速理解目前的支援範圍。

## 支援的欄位同義詞

搜尋語句中若出現以下任一詞彙，系統會將其視為價格欄位並套用數字範圍條件：

- 價格、價錢、價位、售價、price
- 預算、花費、費用、budget
- 特價、優惠價、促銷價、折扣價（對應 `SpecialOffer` 欄位）

## 比較語句解析

除符號寫法（`>=`, `<=`, `>`, `<`, `到`）外，也支援中文自然語句：

- 下限：以上、起、至少、不少於、不低於、之上、超過、大於、多於、高於
- 上限：以下、以內、內、不超過、不高於、之下、小於、少於、不到、低於

例句：

- 「價格 3000 以內」→ `Price <= 3000`
- 「預算 4000 以上」→ `Price >= 4000`
- 「想找 3000 以下的耳機」→ `Price <= 3000`

## 無欄位明示時的判斷

若使用者只輸入「3000 元以上的包」或「3000 到 5000 元的女鞋」，系統會：

1. 透過金額 + 比較詞的樣式判斷上下限（預設套用到 `Price` 欄位）。
2. 解析 `3000~5000 / 3000 到 5000` 這類純數字區間，避免必須輸入「價格」關鍵字。

## 測試覆蓋

`backend/tests/test_price_filters.py` 針對以下情境建立單元測試：

1. 「3000元以上的包包」→ 價格下限
2. 「3000以下的耳機」→ 價格上限
3. 「3000到5000元的女包」→ 區間範圍
4. 「價格 4000 以內的商品」→ 欄位別名 + 中文比較詞
5. 「預算5000以內的咖啡機」→ 新增的「預算」別名
