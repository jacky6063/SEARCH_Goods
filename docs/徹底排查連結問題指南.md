# 🔍 徹底排查「連結無法點選」問題指南

## 📅 更新時間
2025年11月9日 - 調試版本

## 🎯 問題描述
用戶反饋：聊天回應中的電話、地址、網址都無法點選

## 🧪 測試步驟（請按順序執行）

### 步驟 1: 清除瀏覽器快取 ⚠️ **極重要**

這是最常見的問題原因！

#### Chrome / Edge
1. 按 `Cmd+Shift+Delete` (Mac) 或 `Ctrl+Shift+Delete` (Windows)
2. 選擇「快取的圖片和檔案」
3. 時間範圍選「不限時間」
4. 點擊「清除資料」
5. **完全關閉瀏覽器**（不是只關閉分頁）
6. 重新開啟瀏覽器

#### Safari
1. 按 `Cmd+Option+E` 清空快取
2. 或前往「開發」→「清空快取」
3. **完全關閉 Safari**
4. 重新開啟

#### 強制重新載入（適用所有瀏覽器）
- Mac: `Cmd+Shift+R`
- Windows: `Ctrl+Shift+R`
- 或按住 `Shift` 點擊重新整理按鈕

---

### 步驟 2: 開啟開發者工具

1. 按 `F12` 或右鍵點擊 → 檢查
2. 切換到 **Console** 標籤
3. 確保沒有錯誤訊息（紅色文字）

---

### 步驟 3: 送出測試查詢

在聊天框輸入：
```

```

或：


### 步驟 5: 檢查 DOM 元素

#### 5.1 檢查聊天泡泡
1. 在 Console 執行：
```javascript
document.querySelectorAll('.bubble.assistant').length
```
應該返回 > 0（至少有一個助理回應）

#### 5.2 檢查 rich-content 容器
```javascript
document.querySelectorAll('.rich-content-container').length
```
- 如果返回 **0**：前端未渲染（參考「情況 A」）
- 如果返回 **> 0**：容器存在，繼續檢查按鈕

#### 5.3 檢查按鈕
```javascript
document.querySelectorAll('.rich-action-btn').length
```
- 如果返回 **0**：按鈕未創建（參考「情況 B」）
- 如果返回 **> 0**：按鈕存在，檢查 href

#### 5.4 檢查按鈕 href
```javascript
document.querySelectorAll('.rich-action-btn').forEach(btn => {
  console.log('按鈕 href:', btn.href);
  console.log('按鈕文字:', btn.textContent);
});
```
應該看到：
```
按鈕 href: tel:0427062295
按鈕文字: 📞 撥打

按鈕 href: https://www.google.com/maps/search/?api=1&query=...
按鈕文字: 📍 查看地圖
```

## 🔎 問題診斷

### 情況 A: Console 顯示「包含 rich_content: false」

**問題**：後端未返回 rich_content

**解決方法**：

1. 檢查 Network 標籤
2. 找到 `/api/chat` 請求
3. 查看 Response：

```json
{
  "reply": "...",
  "ok": true,
  "rich_content": {  // ← 應該要有這個
    "type": "contact_info",
    "items": [...]
  }
}
```

如果沒有 `rich_content`：
- 後端可能還沒部署最新版本
- 等待 15 分鐘讓部署完成
- 或後端出錯（查看後端日誌）

---

### 情況 B: 有 richContent 但沒有按鈕

**問題**：前端渲染邏輯有誤

**檢查 Console 是否有錯誤**：
```javascript
// 查看是否有 JavaScript 錯誤
console.error('檢查上方是否有紅色錯誤訊息');
```

**手動測試渲染**：
```javascript
// 測試按鈕創建
const testBtn = document.createElement('a');
testBtn.href = 'tel:0427062295';
testBtn.textContent = '測試按鈕';
testBtn.style.cssText = 'padding: 10px; background: green; color: white; border-radius: 5px; display: inline-block; text-decoration: none;';
document.body.appendChild(testBtn);
```

如果測試按鈕可見且可點擊：
- 前端渲染邏輯有 bug
- 需要檢查 `appendChatBubble` 函數

---

### 情況 C: 按鈕存在但無法點擊

**可能原因**：
1. CSS `pointer-events: none`
2. 其他元素遮蓋
3. href 為空

**檢查方法**：
```javascript
// 檢查按鈕狀態
const btn = document.querySelector('.rich-action-btn');
if(btn){
  console.log('按鈕存在:', true);
  console.log('href:', btn.href);
  console.log('pointer-events:', getComputedStyle(btn).pointerEvents);
  console.log('z-index:', getComputedStyle(btn).zIndex);
  console.log('display:', getComputedStyle(btn).display);
}
```

**手動測試點擊**：
```javascript
// 強制觸發點擊
const btn = document.querySelector('.rich-action-btn');
if(btn){
  btn.click();  // 應該開啟連結
}
```

---

### 情況 D: 快取問題（最常見）

**症狀**：
- Console 沒有調試日誌
- 沒有「🔍 [DEBUG]」開頭的訊息
- 看起來像舊版本

**確認方法**：
```javascript
// 檢查快取版本
const metaTag = document.querySelector('head').innerHTML;
console.log('包含 2025-11-09:', metaTag.includes('2025-11-09'));
```

如果返回 `false`：
- **你正在使用舊版快取**
- 請重新執行「步驟 1: 清除瀏覽器快取」
- 務必**完全關閉瀏覽器**後重開

## 🆘 如果還是不行

### 最終檢查清單

#### ✅ 後端檢查
```bash
# 檢查後端日誌
curl -X POST https://your-backend-url/api/chat \
  -H "Content-Type: application/json" \
  -d '{"message": "公司電話是多少？", "history": [], "topn": 8, "session_id": "test"}'

# 應該看到 "rich_content" 欄位
```

#### ✅ 前端檢查
1. 開啟 Sources 標籤
2. 搜尋 `appendChatBubble`
3. 確認函數有 `richContent = null` 參數
4. 確認有 `console.log('[DEBUG]')` 程式碼

#### ✅ 網路檢查
1. Network 標籤
2. 找到 `index.html`
3. 查看 Response Headers
4. 確認沒有 `Cache-Control: max-age=...` (很長時間)

   - `/api/chat` 的完整 JSON 回應

## 🎯 快速自我診斷

| 問題 | Console 訊息 | 原因 | 解決方法 |
|------|-------------|------|---------|
| 完全沒有調試日誌 | 無任何 DEBUG | 瀏覽器快取 | 清除快取 + 重啟瀏覽器 |
| "包含 rich_content: false" | 🔍 DEBUG 存在 | 後端未部署 | 等待 15 分鐘 |
| "richContent: null" | 🎨 DEBUG 存在 | API 回應錯誤 | 檢查 Network 標籤 |
| "沒有 richContent 或 items" | ⚠️ 跳過渲染 | 資料結構錯誤 | 檢查 API 格式 |
| 有日誌但沒按鈕 | ✅ 渲染完成 | DOM 插入失敗 | 檢查 Elements 標籤 |
| 按鈕存在但不能點 | 🔗 創建按鈕 | CSS 或遮蓋 | 檢查 computed styles |

## ✅ 成功標準

測試成功時，您應該看到：

### 視覺上
- 聊天回應下方有**灰色卡片**
- 每個卡片有**彩色按鈕**（綠/紅/藍/紫）
- 滑鼠移到按鈕上會**上浮**

### 功能上
- 點擊電話按鈕 → 開啟撥號介面（手機）
- 點擊地址按鈕 → 開啟 Google Maps
- 點擊網址按鈕 → 開啟新分頁
- 點擊影片按鈕 → 播放 YouTube

### Console 上
- 至少 10 行 DEBUG 訊息
- 所有項目都標記「✅」
- 無任何紅色錯誤
