# 價格區間過濾問題分析報告

## 📋 問題現象

用戶查詢：「我想要找3000~4000元的女用包包」  
系統回傳：4款商品，但其中2款不符合價格條件

**不符合條件的商品**：
- ❌ 品牌訂製大容量時尚斜背包：**2980元** (低於3000元)
- ❌ 格紋裝飾配色兩用後背包：**特價2533元** (低於3000元)

**符合條件的商品**：
- ✅ 柔軟手感牛皮前釦式肩背包：**3980元** (在3000-4000範圍內)
- ✅ 手工刺繡旋轉音符三用包：**3480元** (在3000-4000範圍內)

## 🔍 根因分析

### 1. 波浪號(~)符號未被識別

**測試結果**：
```
查詢: 我想要找3000~4000元的女用包包
預算提取結果: {
    'budget': 4000.0, 
    'budget_info': {
        'max_price': 4000.0, 
        'min_price': None  ← 🔥 問題：最低價沒有被提取
    }
}
```

**原因**：`extract_budget_and_cats` 函數的正則表達式模式中**缺少波浪號(~)模式**

**現有模式**：
```python
budget_patterns = [
    r"(\d{2,})-(\d{2,})(?:元)?",         # 支援 "3000-4000元" ✅
    r"(\d{2,})(?:元)?到(\d{2,})(?:元)?", # 支援 "3000元到4000元" ✅
    # 缺少: r"(\d{2,})~(\d{2,})(?:元)?"  # 不支援 "3000~4000元" ❌
]
```

### 2. 系統只應用了最高價限制

**結構化過濾結果**：
```python
{
    'category_filter': '包',
    'must_have_keywords': ['背包', '包'],
    'excluded_keywords': ['湯', '燉包', '茶', '醬', '調味', '湯包'],
    'price_filter': {
        'max_price': 4000.0  # 只有最高價，沒有最低價 ❌
    }
}
```

**實際過濾效果**：
- 所有 ≤ 4000元 的商品都通過了過濾 ❌
- 應該是 3000 ≤ 價格 ≤ 4000 的商品才通過 ✅

### 3. 測試驗證

**波浪號模式測試**：
```python
# 測試文本: "我想要找3000~4000元的女用包包"
# 現有模式無法匹配，但手動測試波浪號模式：
pattern = r"(\d{2,})~(\d{2,})(?:元)?"
matches = [('3000', '4000')]  # ✅ 能正確匹配
```

**價格過濾測試**：
```python
# 當前系統過濾 (只有最高價)
price_filter = {'max_price': 4000.0}
結果: 4/4 商品通過 ❌

# 正確的價格區間過濾
price_filter = {'min_price': 3000.0, 'max_price': 4000.0}  
結果: 2/4 商品通過 ✅
```

## 🎯 解決方案

### 1. 新增波浪號(~)模式支援

**需要在 `utils/simple_extract.py` 中新增**：
```python
budget_patterns = [
    # 現有模式...
    r"(\d{2,})~(\d{2,})(?:元)?",         # 新增: "3000~4000元"
    r"(\d{2,})(?:元)?~(\d{2,})(?:元)?",  # 新增: "3000元~4000元"
]
```

### 2. 優化模式順序

將範圍模式放在前面，避免被單一數字模式搶先匹配：
```python
budget_patterns = [
    # 範圍模式 (優先)
    r"(\d{2,})-(\d{2,})(?:元)?",        # "3000-4000元"
    r"(\d{2,})~(\d{2,})(?:元)?",        # "3000~4000元" (新增)
    r"(\d{2,})(?:元)?到(\d{2,})(?:元)?", # "3000元到4000元"
    
    # 單一限制模式 (次要)
    r"(\d{2,})(?:元)?(?:以下|內|以內)", # "2500元以下"
    # ...其他單一模式
]
```

### 3. 測試案例補強

需要新增波浪號相關的測試案例：
```python
def test_tilde_range_extraction(self):
    """測試波浪號價格範圍"""
    result = extract_budget_and_cats("3000~4000元的包包")
    assert result["budget_info"]["min_price"] == 3000
    assert result["budget_info"]["max_price"] == 4000
```
