## 🧪 測試步驟（重要！）

### 步驟 1: 清除瀏覽器快取 ⚠️ **極重要**

這是最重要的步驟，90% 的「沒有更新」問題都是快取造成的！

#### Chrome / Edge
```
1. 按 Cmd+Shift+Delete (Mac) 或 Ctrl+Shift+Delete (Windows)
2. 選擇「快取的圖片和檔案」
3. 時間範圍選「不限時間」
4. 點擊「清除資料」
5. ⚠️ 完全關閉瀏覽器（所有視窗）
6. 重新開啟瀏覽器
```

#### Safari
```
1. 按 Cmd+Option+E 清空快取
2. 完全關閉 Safari
3. 重新開啟
```

#### 強制重新載入
```
Mac: Cmd+Shift+R
Windows: Ctrl+Shift+R
```

---

### 步驟 2: 檢查前端版本

1. 開啟生產環境網站
2. 按 `F12` 開啟開發者工具
3. 切換到 **Console** 標籤
4. 執行以下指令：

```javascript
// 檢查快取版本
document.querySelector('head').innerHTML.includes('2025-11-09')
```

**預期結果**:
- ✅ 返回 `true` → 前端已更新
- ❌ 返回 `false` → 還在用舊版快取，重新執行步驟 1

## 🐛 如果測試失敗

### 情況 1: 完全沒有按鈕

**原因**: 快取問題或部署未完成

**解決**:
1. 再次清除快取（步驟 1）
2. 等待 5 分鐘讓部署完成
3. 使用無痕模式測試

### 情況 2: 沒有 DEBUG 日誌

**原因**: 使用舊版前端

**解決**:
1. 執行版本檢查（步驟 2）
2. 如果返回 `false`，重新清除快取
3. 完全關閉瀏覽器後重開

### 情況 3: 有按鈕但無法點擊

**原因**: DOM 或 CSS 問題

**診斷**:
```javascript
// 檢查按鈕是否存在
document.querySelectorAll('.rich-action-btn').length

// 檢查第一個按鈕
const btn = document.querySelector('.rich-action-btn');
console.log('href:', btn?.href);
console.log('pointer-events:', getComputedStyle(btn)?.pointerEvents);
```

### 情況 4: API 沒有返回 rich_content

**原因**: 後端未部署或有錯誤

**診斷**:
1. 開啟 Network 標籤
2. 送出查詢
3. 找到 `/api/chat` 請求
4. 查看 Response，確認有 `rich_content` 欄位
